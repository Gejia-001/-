Operating systems manage the hardware and software resources of a computer. A modern system allows many programs to run at the same time, and each program may contain several threads of execution. A thread is the smallest unit that the scheduler can dispatch on a processor. All threads of one process share the same address space, so they can read and write the same global variables without any special instruction. This sharing makes communication fast and cheap, but it also creates a serious danger. When two threads update one variable at the same moment, one update can be lost. Programmers must therefore protect every shared structure with a lock or a semaphore. A correct program never assumes that an unprotected update happens in one single step.
