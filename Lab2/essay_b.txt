Mutual exclusion is the basic idea behind every synchronization primitive. A semaphore is an integer variable that a thread can only touch through two atomic operations. The wait operation decreases the value and blocks the caller when the value would become negative. The post operation increases the value and wakes one waiting thread. When the initial value is one, the semaphore behaves exactly like a lock, so only one thread can enter the critical section at a time. The order in which blocked threads wake up is not defined by the standard, and a program that depends on that order is fragile. Counting semaphores with larger initial values are useful for controlling access to a pool of identical resources such as a fixed number of buffers.
